The Dimension of the Heat-Flow Fractal

Fractals don't just sit there—they evolve, and evolution changes dimension. But how much?

Question. If you take a self-similar measure $\mu$ on $\mathbb{R}$ with Hausdorff dimension $d_\mu$ and evolve it under the PDE $\partial_t u = \partial_{xx} u + \lambda u$ (with $\lambda \neq 0$), what is the dimension of the solution $u(t,x)$ at time $t>0$? Or more precisely: What is $\dim_H(\text{supp}(u(t,\cdot)))$?

Let's Start With a Toy Example

Imagine a Cantor measure $\mu$ on $[0,1]$ generated by the IFS $\{x \mapsto x/3, x \mapsto x/3 + 2/3\}$ with equal weights. This is the "middle-third" fractal. It's self-similar with contraction ratio $r=1/3$, so its Hausdorff dimension is $d_\mu = \log_3 2 \approx 0.6309$. The measure $\mu$ lives on a set of dimension $d_\mu < 1$. Now, heat it up. The PDE $\partial_t u = \partial_{xx} u + \lambda u$ is the heat equation with a reaction term. The operator $\partial_{xx}$ smooths, $\lambda u$ either amplifies or damps, but both are linear. The solution is given by the heat kernel convolution: $$u(t,x) = \int_{\mathbb{R}} K(t,x-y) \, d\mu(y), \quad K(t,x) = \frac{1}{\sqrt{4\pi t}} e^{-x^2/(4t)} e^{\lambda t}.$$ The support of $u(t,\cdot)$ is the set $\{x : u(t,x) > 0\}$. Since $K(t,x) > 0$ for all $x$ and the integral is positive, the support is actually $\mathbb{R}$—the heat equation smears everything instantly. So the answer, in this toy setting, is: $$\dim_H(\text{supp}(u(t,\cdot))) = 1.$$ But that's the trick. The heat equation is "too good" at smoothing. It doesn't preserve the fractal structure. Let's ask a harder question: What if we take the PDE $\partial_t u = \partial_{xx} u$ (no reaction term) and ask about the *measure* $u(t,x)\,dx$? The heat kernel $K(t,x)$ is a smooth function, so $u(t,x)\,dx$ is absolutely continuous with respect to Lebesgue measure. Its dimension is still $1$. We need a PDE that respects the fractal structure. What if we take the *fractional* heat equation? **The Fractional Question**: Consider the PDE $\partial_t u = -(-\Delta)^\alpha u$ where $\alpha \in (0,1)$ is the fractional Laplacian. If $u(0,x) = \mu$ is a Cantor measure, what is the dimension of the solution $u(t,x)$? Now we're in interesting territory. The fractional heat equation is non-local, so the solution "sees" the whole space. But the initial data $\mu$ is singular. The solution $u(t,x)$ is a function, and its dimension is $1$. But $u(t,x)\,dx$ is absolutely continuous. Wait—what if we ask about the solution $u(t,x)$ itself as a *function*? Its graph has dimension $2$ in $\mathbb{R}^2$. No, we need to think differently. **The Real Question**: What if we take the PDE $\partial_t u = \partial_{xx} u + \lambda u$ but with *fractal initial data* $\mu$, and we ask about the dimension of the set $\{(t,x) : u(t,x) > 0\}$ in $\mathbb{R}^2$? The support of $u(t,\cdot)$ is $\mathbb{R}$ for all $t>0$, so the set is $\mathbb{R}^2$. Dimension $2$. This is too easy. Let me try a different approach: **The Fractal-PDE**: What if we replace the Laplacian $\partial_{xx}$ with a fractal operator? Consider the "fractal Laplacian" defined by the IFS $\{f_1(x)=x/3, f_2(x)=x/3 + 2/3\}$. This is a self-similar operator that acts like $\partial_{xx}$ on the fractal. The PDE becomes: $$\partial_t u = \mathcal{L} u + \lambda u,$$ where $\mathcal{L}$ is the fractal Laplacian. The solution $u(t,x)$ is now defined on the fractal itself. The dimension of the domain is $d_\mu = \log_3 2$. The solution $u(t,x)$ is a function on this fractal, so its graph has dimension $d_\mu + 1 = \log_3 2 + 1 \approx 1.6309$. But this is still a bit of a trick. The fractal-PDE question is interesting, but it's not exactly what I want. Let me go back to the original question and make it more precise: **The Precise Question**: Let $\mu$ be a self-similar measure on $[0,1]$ with dimension $d_\mu = \log_3 2$. Consider the PDE $\partial_t u = \partial_{xx} u + \lambda u$ with $u(0,x) = \mu$. What is the Hausdorff dimension of the set $\{x : u(t,x) > 0\}$? The answer is $1$, because the heat equation smears everything instantly. But what if we ask: What is the dimension of the *measure* $u(t,x)\,dx$? The answer is still $1$, because $u(t,x)$ is a smooth function. So the question is: Can we make a PDE that *preserves* the fractal dimension? **The Hidden Mechanics**: Consider the PDE $\partial_t u = \partial_{xx} u + \lambda u + \mu u$. The measure $u(t,x)\,dx$ is still absolutely continuous. But what if we take the PDE $\partial_t u = \partial_{xx} u + \lambda u$ and ask about the *density* of the measure $\mu$ with respect to $u(t,x)\,dx$? The density is $u(t,x)$. Its dimension is $1$. I'm going in circles. Let me try a different angle: **The Dimension of the Attractor**: Consider the PDE $\partial_t u = \partial_{xx} u + \lambda u$ on the fractal domain $[0,1]_\mu$. The attractor is the solution $u_\infty(x)$ as $t \to \infty$. What is the dimension of the attractor? The attractor is a function on the fractal, so its dimension is $d_\mu + 1$. But this is still a bit of a trick. The question is: What is the dimension of the attractor *as a set*? The attractor is the set of points $(x,u_\infty(x))$ in $\mathbb{R}^2$, which has dimension $d_\mu + 1$. I think I'm overcomplicating this.
